Enable live AI

  1. Create a free API key with one of the providers below.
  2. Set environment variables on the server (locally in a .env file; on Render under Environment): 
    LLM_PROVIDER=gemini
GEMINI_API_KEY=your-key-here
LLM_MODEL=gemini-2.5-flash   # optional
  3. Restart the app. The badge in the sidebar changes to Live AI.

Keys are read only on the server. They are never sent to the browser, stored in the database or written to logs.

Safeguards built into every mode

No invented policy

Citations must come from retrieved handbook sections; quotes must be verbatim. The gate removes anything else.

No invented law

Legal frameworks are named only from the handbook's own reference map, always marked “requires verification”.

POSH routing

Sexual-harassment indicators route the case to the Internal Committee path, hide complaint details and restrict access.

Urgent risk first

Threats, violence and self-harm indicators are flagged at intake, before any agent runs.

Allegations stay allegations

Only case-record facts are "confirmed". Guilt, credibility and penalty language is removed.

Data minimisation

Phone numbers, emails and ID-like numbers are redacted from prompts and reports. Uploaded documents are treated as data, never as instructions.

Security and privacy of this deployment

  • Each browser gets its own workspace (a random cookie). Cases are not visible to other visitors — but this is isolation, not authentication. Anyone with your browser can see your cases.
  • {% if access_code_enabled %}This deployment is protected by a shared access code.{% else %}No access code is set. Set APP_ACCESS_CODE to require one before anyone can open the app.{% endif %}
  • On free hosting, the database is temporary and may be wiped on restart. Use synthetic cases only — this is not a production HR system.
